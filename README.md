# 🏀 科比·布莱恩特 — 人物介绍页

《软件开发综合实践》课程作业，使用纯 HTML + CSS 手工编写的单页介绍网页。

## 简介

本仓库是一个关于 NBA 传奇球星**科比·布莱恩特**（Kobe Bryant）的单页介绍网站，内容涵盖人物简介、曼巴精神、职业生涯主要成就、相关参考链接和经典瞬间配图。

## 目录结构

```
git-practice/
├── README.md              # 本文件，仓库说明
├── kobe.html              # 主页，科比人物介绍页（核心文件）
├── hello.txt              # 实验用测试文件
├── images/
│   └── kobe.webp          # 科比定妆照，页面引用的本地图片
└── git-practice/          # 早期实验残留的嵌套目录（可忽略）
    ├── homepage/
    ├── index/
    └── hello.txt
```

## 技术栈

- HTML5（语义化标签：h1 / h2 / p / ol / ul / a / img / footer）
- 内联 CSS（湖人队紫金配色主题）
- 无任何外部框架依赖，纯手写

## 本地预览

直接双击打开 `kobe.html` 即可，或在终端运行：

```bash
# 方式一：直接打开
start kobe.html

# 方式二：Python 起一个简易服务器（需要 Python 3）
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000/kobe.html
```
